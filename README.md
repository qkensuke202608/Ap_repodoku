# レポポ・読！ (Repopo-Doku)
**文章が苦手な高校生でもスマホでスイスイ！教科書・長文読解レポート作成ナビ**

「レポポ・読！」は、教科書や長文読解からレポートを作成する高校生をサポートするために設計されたWebアプリケーションです。  
Appleのデザイン賞水準の滑らかな触感・操作性、親しみやすいカラフル＆ポップなデザイン、全44px以上の丸型ボタンシステムを採用し、スマートフォンでの快適な操作を実現しています。

---

## 主な特徴

1. **Appleデザイン賞クオリティのUI/UX**
   - 美しいグラスモーフィズム（すりガラス効果）と弾むようなスプリングアニメーション
   - 高校生が楽しく取り組めるカラフルで明るいカラーパレット
   - 親指だけで直感操作できる画面下部の「フローティング・アクション・ドック」

2. **押しやすい丸型ボタン設計（44px以上厳守）**
   - 下部ドックのメインボタンは直径60px〜62pxの大型丸型ボタン
   - 入力・追加・削除・コピー・クリアの各ボタンも44px以上の快適なタッチ領域

3. **4ステップのスムーズなレポート作成フロー**
   - **手順1：教科書からセンテンス抜き出し**  
     ①テーマタイトルや見出し、②わかったこと・理解したこと、③このテーマで言いたかったこと を付箋カードとしてポンポン抜き出し・追加・クリア。
   - **手順2：教科書レポート・穴埋めテンプレート**  
     抜き出した付箋をタップするだけで穴埋めスロットに即座に反映。直接手入力も可能。
   - **手順3：200字以内の文章を作ってみる**  
     テンプレートから自動生成された文章を自由に編集。リアルタイム文字数カウンター（`/200字`）とプログレスバー、200字以内調整機能、箇条書きからの再生成機能。
   - **手順4：ChatGPT添削 & コピー & 共有**  
     高校生向け添削プロンプトを自動コピーしてChatGPT（別タブ）を開くボタン、ワンタップコピーボタン、スマホの「メモ」やLINE等への共有ボタン。

4. **ホーム画面アプリアイコン完全対応（iOS / Android / PC）**
   - `img/repo_doku_icon.png` をPC用Favicon、iOS用apple-touch-icon、Android PWA、Windowsタイルのすべてに最適設定。
   - Safariで「ホーム画面に追加」またはChromeで「アプリをインストール」することで、ネイティブアプリのように使えます。

5. **安心のLocalStorage自動保存 & 見本投入機能**
   - 入力中の付箋や文章はブラウザに自動保存されるため、途中で画面を閉じても安心。
   - 「見本を入れる（🪄）」ボタンで、現代文（夏目漱石『こころ』）の記入例を1タップで展開して試すことができます。

```text

├── index.html        # アプリ構造・アイコンメタタグ・マークアップ
├── css/
│   └── style.css     # Apple風デザインシステム・丸ボタン・カラフル配色

```

## 使い方・プレビュー

ブラウザで `index.html` を開くだけですぐに動作します。
スマートフォンでの動作確認時は、ブラウザの開発者ツールでモバイルビュー（iPhone 14/15/16など）に切り替えるか、ローカルサーバー経由で実機アクセスしてください。
